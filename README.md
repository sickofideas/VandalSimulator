# 3D Vandal Simulátor

Komický low-poly sandbox: vyber si postavičku a ničí budovy a auta na reálné mapě České republiky (začínáme Příbramí).

- **Hrát v prohlížeči:** https://sickofideas.github.io/VandalSimulator
- **Engine:** Unity 6.3 LTS (URP)
